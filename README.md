Shoes Shop

Shoes Shop is a frontend e-commerce website for browsing and shopping for shoes and other footwear products.

The project was originally created as one of my early frontend projects using only HTML and CSS. After gaining more experience with modern frontend development, I revisited the project and decided to rebuild it using a more modern frontend stack.

The current version is being rebuilt with React, TypeScript, and Tailwind CSS v4, with the goal of improving the component structure, maintainability, responsiveness, and overall code quality.

✨ Features

Currently implemented:

- Browse and display shoe products
- Sign in / login interface
- Product-focused e-commerce UI

The project is currently being refactored, so some features and interactions are still under development.

🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS v4
- Vite

📁 Project Structure

src/
├── components/
├── assets/
├── App.tsx
└── main.tsx

The project is currently built as a single-page application, so React Router is not used at this stage.

🔄 Why I Rebuilt This Project

Shoes Shop started as one of my early projects when I was learning frontend development.

The original version was built using only HTML and CSS. After gaining more experience with React and modern frontend development, I decided to revisit the project and rebuild it from scratch.

Instead of simply leaving the old project as it was, I wanted to use it as an opportunity to apply what I have learned since then.

Through this refactoring process, I am focusing on:

- Rebuilding the UI with React components
- Improving component structure and reusability
- Introducing TypeScript
- Replacing traditional CSS with Tailwind CSS
- Rebuilding the responsive layout
- Improving maintainability
- Gradually transforming a static frontend into a more interactive e-commerce experience

The project is still a work in progress and will continue to evolve as new features are implemented.

📱 Responsive Design

The original project was not responsive.

As part of the current refactoring process, the responsive design is being rebuilt from scratch using Tailwind CSS v4, with the goal of providing a better experience across different screen sizes.

🚀 Getting Started

Clone the repository:

```
git clone https://github.com/saba-sh80/Shoes-shop.git
```

Navigate to the project directory:

```
cd shoes-shop
```

Install dependencies:

```
npm install
```

Start the development server:

```
npm run dev
```

The application will then be available on the local development server provided by Vite.
