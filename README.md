# Shoes-shop

A responsive online shoe store web application originally built with plain HTML and CSS, now refactored using React and Vite. This project breaks down the UI into reusable components as part of an ongoing transition from a static setup to a fully dynamic web app.

## 🚀 Technologies Used

React Js
Vite
Tailwind CSS


## 🛠️ Installation and Setup

Follow these steps to run the project locally on your machine:

1. Clone the repository:
git clone https://github.com/saba-sh80/Shoes-shop.git



2. Navigate to the project directory:
cd repository-name



3. Install dependencies:
npm install



4. Start the development server:
npm run dev
